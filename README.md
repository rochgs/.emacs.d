## Installation

Last test of installation: fresh new Debian 13 system.

### Prerequisites

- [Git](https://git-scm.com/).
- [Emacs](https://www.gnu.org/software/emacs/).
- [JetBrains Mono Slashed font](https://github.com/sharpjs/JetBrainsMonoSlashed).
- `hunspell` and `hunspell-es`:

    ```
    sudo apt install hunspell hunspell-es
    ```

### Procedure

Just clone the repository contents to `~/.emacs.d/` and start Emacs.
